# 网页填写助手

一个智能的浏览器扩展，自动识别网页表单并填充数据。

## 功能特点

- **智能识别**：自动识别网页上的表单字段（输入框、下拉框、单选框、复选框等）
- **模糊匹配**：支持字段名的模糊匹配，即使字段名不完全一致也能正确填充
- **多种格式**：支持 JSON 格式和 "键: 值" 格式输入数据
- **语义分析**：内置常见字段类型（姓名、电话、邮箱、地址等）的智能识别
- **实时预览**：输入数据时实时显示已解析的字段
- **数据持久化**：自动保存上次输入的数据

## 安装方法

### 方法1：开发者模式加载（推荐）

1. 打开 Chrome/Edge 浏览器，进入扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

2. 开启右上角的"开发者模式"

3. 点击"加载已解压的扩展程序"

4. 选择本项目文件夹

5. 扩展图标会出现在浏览器工具栏中

### 方法2：打包安装

1. 在扩展管理页面点击"打包扩展程序"

2. 选择本项目文件夹

3. 将生成的 `.crx` 文件拖拽到扩展管理页面安装

## 使用方法

### 1. 输入数据

点击扩展图标，在弹出窗口中输入要填充的数据。支持两种格式：

**格式1：键值对格式（推荐）**
```
姓名: 张三
手机号: 13800138000
邮箱: zhangsan@example.com
地址: 北京市朝阳区
```

**格式2：JSON 格式**
```json
{
  "姓名": "张三",
  "手机号": "13800138000",
  "邮箱": "zhangsan@example.com",
  "地址": "北京市朝阳区"
}
```

### 2. 扫描表单

点击"扫描表单"按钮，扩展会自动分析当前页面的表单字段。

### 3. 自动填充

点击"自动填充"按钮，扩展会根据字段名智能匹配并填充数据。

## 支持的字段类型

| 字段类型 | 匹配关键词 |
|---------|-----------|
| 姓名 | 姓名、名字、name、username |
| 手机号 | 电话、手机、phone、mobile、tel |
| 邮箱 | 邮箱、邮件、email、e-mail |
| 地址 | 地址、address、addr |
| 城市 | 城市、city、市 |
| 省份 | 省份、省、province |
| 邮编 | 邮编、zip、postal |
| 身份证 | 身份证、idcard |
| 公司 | 公司、单位、company |
| 部门 | 部门、department |
| 职位 | 职位、岗位、position |
| 性别 | 性别、gender、sex |
| 生日 | 生日、birthday、birth |

## 匹配算法

扩展使用多维度匹配算法：

1. **完全匹配**：字段名与数据键完全一致
2. **包含匹配**：字段名包含数据键或反之
3. **相似度匹配**：使用 Levenshtein 距离计算字符串相似度
4. **语义匹配**：基于预定义的字段类型进行智能匹配

## 技术说明

- **Manifest V3**：使用最新的 Chrome 扩展标准
- **内容脚本**：在网页上下文中运行，直接操作 DOM
- **消息通信**：popup 与 content script 通过 Chrome API 通信
- **智能识别**：基于语义分析和字符串相似度算法

## 注意事项

1. 扩展需要获取当前标签页的权限才能操作表单
2. 某些网站可能有安全限制，导致无法正常填充
3. 建议在使用前先在非重要页面测试
4. 敏感信息（密码等）请谨慎使用
